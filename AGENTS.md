# Recoscope publication workflow

Before publishing a benchmark run or activating its category, follow
[docs/benchmark-publication-checks.md](docs/benchmark-publication-checks.md).
Include every new most-mentioned brand and all tied leaders in the logo
preflight, together with existing homepage leaders. A failed or incomplete
check must be resolved before the run becomes public. Add official local logo
assets and mappings before publication; preserve all benchmark counts/ranks.
After publication, run the live logo check and verify every card image in the
browser on desktop and mobile, including lazy-loaded/off-screen cards.
